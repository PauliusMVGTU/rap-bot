## Project
A semi-trained model made for the purpose of university work

## Objective
The objective of this work was to use Natural Language Processing to train an AI Rap bot which could battle with a different Rap bot if given a shared .txt file with the previous Rap bot input

## Model
A Rap bot which was trained on this [Kaggle dataset](https://www.kaggle.com/datasets/ceebloop/rap-lyrics-for-nlp)

## Notes
The bot was not trained for a long time - way better results can be expected if trained for longer
